A chess engine that fits in 4,096 bytes of Python. It plays make.fun's house gauntlet over HTTP: iterative-deepening alpha-beta with a transposition table, quiescence search, and a fixed node budget per move so every game replays identically.

## Run it

```sh
MAKEFUN_ENV_URL=http://127.0.0.1:8080 python3 -P -s main.py
```
